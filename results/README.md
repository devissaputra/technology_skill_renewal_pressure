# Results

`empirical_summary.json` is the machine-readable release summary for **Technology Skill Renewal Pressure: O*NET 2020–2026**.

It distinguishes:
- all-release pair-set overlap;
- overlap restricted to the 902 common occupations;
- the full occupation-level Jaccard distribution;
- category-name sensitivity results;
- pair-level Hot Technology / In Demand counts after deduplication.

Every headline distribution value is checked against `data/derived/primary_results.csv`, which contains all 902 common occupations. The summary should not be edited independently of the pipeline, derived tables, tests, and documentation.
