## Why this bundle is distinct
This repository studies **version-to-version occupational software-skill portfolio turnover** in O*NET. The unit of analysis is an occupation–software portfolio, not an individual learner, competency profile, training intervention, recommendation, or engagement outcome.

## Distinctness dimensions
1. **Unit:** O*NET occupation portfolios.
2. **Question:** persistence and renewal of software requirements.
3. **Source:** versioned O*NET database releases.
4. **Method:** longitudinal set overlap plus distributional and category sensitivity analysis.
5. **Output:** reproducible workforce-renewal evidence table across 902 occupations.

“Original” here means materially distinct within this portfolio. It does not imply that occupational skill-change research or Jaccard similarity is academically novel.
