## Source interpretation used in this repository
O*NET's 31.0 data dictionary documents that release 30.3 renamed Technology Skills to Software Skills and renamed Example / Commodity Code / Commodity Title to Workplace Example / Element ID / Element Name. It also states that 30.3 is the most recent Software Skills content update.

The release archive identifies O*NET 31.0 as the August 2026 production database and points longitudinal researchers to O*NET's longitudinal update resources.
